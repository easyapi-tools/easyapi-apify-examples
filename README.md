# EasyAPI · Apify Actor examples

Copy-paste **input.json** samples for [EasyAPI](https://apify.com/easyapi) Actors on Apify.

These examples pair with crawlable landing pages on **[easyapi.tools](https://easyapi.tools)** (not a mirror of the full site — just runnable inputs + short notes).

## Examples

| Folder | Landing | Apify Actor |
|--------|---------|-------------|
| [`google-trends-scraper/`](./google-trends-scraper/) | [easyapi.tools/google-trends-scraper](https://easyapi.tools/google-trends-scraper/) | [google-trends-keywords-discovery-tool](https://apify.com/easyapi/google-trends-keywords-discovery-tool) |
| [`google-news-scraper/`](./google-news-scraper/) | [easyapi.tools/google-news-scraper](https://easyapi.tools/google-news-scraper/) | [google-news-scraper](https://apify.com/easyapi/google-news-scraper) |
| [`facebook-ads-library/`](./facebook-ads-library/) | [easyapi.tools/facebook-ads-library](https://easyapi.tools/facebook-ads-library/) | [facebook-ads-library-scraper](https://apify.com/easyapi/facebook-ads-library-scraper) |

## How to run

1. Open the Actor on Apify (link above).
2. Paste the folder’s `input.json` into the Input tab (or save as a task).
3. Start the run. Adjust `maxItems` / geo fields as needed.
